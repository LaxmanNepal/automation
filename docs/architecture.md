# Laxman OS Architecture

## Roles

**ChatGPT** — research, summarize, prioritize, draft, and recommend the next human-approved action.

**GitHub** — store configuration, code, reports, issues, pull requests, and history.

**GitHub Actions** — run deterministic scheduled checks and generate reports.

**Laxman** — approve consequential changes, review code, publish content, and make financial decisions.

## Core loop

Research → Opportunity/Problem → Priority → Action Queue → Build/Fix → Test → Report → Human Review → Measure

V1 intentionally avoids requiring paid AI APIs. AI-assisted research can happen through ChatGPT while GitHub Actions handles repeatable engineering work.
