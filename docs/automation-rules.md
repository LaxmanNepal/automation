# Automation Rules

## Automatically allowed
- Validate configuration.
- Inspect configured repositories.
- Generate reports and diagnostic artifacts.
- Run existing tests and linters.

## Human approval required
- Merge pull requests.
- Publish public content.
- Send external messages.
- Change production infrastructure.
- Delete data or repositories.
- Make investments or trades.
- Spend money.

## Priority model
Prefer work with revenue potential, audience/search growth, reusable asset value, automation leverage, low implementation cost, and measurable outcomes.

A priority score is only a queueing aid; it is never an instruction to act automatically.
