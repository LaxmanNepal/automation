# Revenue Asset Engine

This engine converts current money-opportunity research into implementation-ready digital-asset specifications.

## Schedule

- 10:30 Kuwait daily (`30 7 * * *` UTC)
- Manual workflow dispatch is also available.

## Pipeline

`research bank -> live interest signals -> asset specification`

Each specification contains:
- target problem and audience
- proposed asset
- monetization path
- MVP feature checklist
- SEO checklist
- definition of done
- suggested low-cost stack

## Outputs

- `data/assets/latest.json`
- `reports/assets/YYYY-MM-DD.md`
- `reports/assets/latest.md

## Safety

This engine does not spend money, launch a product, publish content, or automatically create a commercial commitment. Demand and monetization must be validated before execution.
